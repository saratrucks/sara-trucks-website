# بنية التحرير المباشر للمدير

## القرار

ستظل واجهة الموقع مبنية بـ React وVite، مع إضافة وظائف خادم صغيرة تحت مجلد `api/` تعمل على Vercel. تسجّل واجهة المدير الدخول من داخل الموقع، لكن التحقق من كلمة المرور وتوقيع الجلسة واستخدام رمز GitHub تتم جميعها على الخادم فقط.

بعد تسجيل الدخول، تظهر أزرار التعديل والإضافة والحذف داخل صفحات الشاحنات والمقطورات والمعدات. عند الحفظ، ترسل الصفحة البيانات إلى وظيفة خادم محمية، وتقوم الوظيفة بتحديث ملف البيانات في مستودع GitHub. يؤدي ذلك إلى إعادة نشر Vercel تلقائياً، فتظهر التغييرات للعامة بعد اكتمال النشر.

## أسباب هذا الاختيار

النسخة الحالية تستخدم بيانات TypeScript ثابتة ويُعاد نشرها من GitHub إلى Vercel. هذا الأسلوب يحافظ على الاستضافة الحالية دون قاعدة بيانات مدفوعة، ويتيح للمدير تنفيذ كل شيء من واجهة الموقع. أما الصفحة القديمة فكانت تتضمن كلمة مرور ثابتة داخل كود المتصفح وتطلب رمز GitHub في المتصفح، وهو وضع غير آمن ويجب إزالته.

## الحماية

ستُحفظ `ADMIN_PASSWORD` و`ADMIN_SESSION_SECRET` و`GITHUB_TOKEN` في متغيرات بيئة Vercel غير المسبوقة بـ `VITE_` حتى لا تدخل في حزمة المتصفح. ستستخدم الجلسة Cookie موقعة من نوع `HttpOnly` و`Secure` و`SameSite=Strict`، مع التحقق من أصل الطلب، وفلترة الحقول، ووضع حدود لحجم ونوع الصور.

## نتيجة فحص النسخة الحية

عند فتح `https://www.sara-trucks.com/admin` تظهر صفحة تطلب كلمة مرور ورمز GitHub داخل المتصفح. أثبت فحص المصدر أن كلمة المرور القديمة ثابتة داخل ملف الواجهة، وأن رمز GitHub يُخزّن في `sessionStorage` ثم يُرسل مباشرة من المتصفح إلى GitHub. يجب إزالة هذا المسار بالكامل. كما أن شاشة اختيار اللغة كانت تظهر قبل صفحة الإدارة عند أول زيارة، لذلك سيجري استثناء مسار الإدارة من بوابة اختيار اللغة لتسهيل دخول المدير.

صفحات كتالوج الشاحنات والمقطورات والمعدات تحتوي أيضًا على رابط عام بعنوان `Edit Data` يفتح GitHub. سيُحذف هذا الرابط العام ويُستبدل بزر داخلي لا يظهر إلا بعد تحقق جلسة المدير على الخادم.

## التحقق البصري المحلي

جرى فتح مسار `/admin` في نسخة التطوير بعد التعديل. تظهر صفحة الدخول مباشرة دون المرور بشاشة اختيار اللغة، وتحتوي على حقل كلمة مرور واحد وزر دخول آمن فقط. لم يعد حقل GitHub Token ظاهراً في الواجهة، كما أن الألوان والخطوط متوافقة مع الهوية الداكنة والزرقاء للموقع.

بعد تفعيل وضع المعاينة المحلي الخاص بالتطوير، ظهرت لوحة الإدارة الكاملة بثلاثة تبويبات للشاحنات والمقطورات ومعدات البناء، وبطاقات واضحة تتضمن أزرار تعديل وحذف، وزر إضافة عنصر جديد. كما جرى فتح نموذج تعديل شاحنة والتأكد من ظهور الحقول الأساسية والفنية، معاينة الصورة، زر رفع صورة، وزر الحفظ والنشر ضمن نافذة قابلة للتمرير.

## إعداد صلاحية الحفظ

جرى تسجيل الدخول إلى حساب GitHub المالك للمستودع وبدء إنشاء رمز Fine-grained باسم `sara-trucks-inline-admin`. سيقتصر الرمز على مستودع `sara-trucks-website` وصلاحية Contents للقراءة والكتابة فقط، ثم يُحفظ في متغيرات Vercel السرية ولا يُرسل إلى المتصفح.

تم اختيار خيار **Only select repositories** وتحديد `saratrucks/sara-trucks-website` بوصفه المستودع الوحيد الذي يستطيع الرمز الوصول إليه.

أُضيفت صلاحية **Contents** وحدها من صلاحيات المستودع، إضافة إلى **Metadata: Read-only** التي يفرضها GitHub تلقائياً. لا توجد أي صلاحيات للحساب أو لمستودعات أخرى.

تم ضبط **Contents** على **Read and write** حتى تتمكن وظيفة الخادم من قراءة SHA الحالي ثم تحديث ملفات البيانات والصور. بقيت Metadata للقراءة فقط كما يفرض GitHub.

تم إنشاء الرمز بنجاح دون تاريخ انتهاء، لأنه مخصص لوظيفة الموقع المستمرة. لا تُحفظ قيمة الرمز في المستودع أو وثائق المشروع؛ ستوضع فقط داخل متغير البيئة السري `GITHUB_TOKEN` على Vercel.

تم تسجيل الدخول إلى حساب Vercel المرتبط بمشروع `sara-trucks-website-vxzb`. صفحة Environment Variables لا تحتوي متغيرات مخصصة حالياً، ولذلك ستضاف `GITHUB_TOKEN` و`ADMIN_PASSWORD` و`ADMIN_SESSION_SECRET` كأسرار خادم جديدة.

بدأ إنشاء رمز Vercel مؤقت باسم `sara-trucks-admin-setup` لاستخدامه مرة واحدة في إضافة الأسرار وإعادة النشر. لن تُحفظ قيمته في المستودع، وسيُلغى بعد اكتمال التحقق الحي.

تم تقييد رمز Vercel بفريق **SaraTrucks** ثم بالمشروع `sara-trucks-website-vxzb` وحده، بدل منحه وصولاً كاملاً إلى الحساب أو بقية المشاريع.
